# Base Bulk Sender

A Web3 bulk token transfer application for sending tokens on **Base Network** to multiple wallet addresses in a single operation.

Base Bulk Sender is designed to work with **AWE Wallet**. Install the AWE Wallet Chrome extension and connect it to use the bulk sending functionality.

## Live App

https://www.dremart.com/web3/base-bulk-sender/

## AWE Wallet Required

Base Bulk Sender currently supports **AWE Wallet** for wallet connection and transaction approval.

Install AWE Wallet from the Chrome Web Store:

https://chromewebstore.google.com/detail/awe-wallet/pocegdpjahidghlpengkhaiancfpnapn

After installing AWE Wallet, return to the Base Bulk Sender and connect your wallet.

## Features

- Bulk token transfers on Base Network
- Send tokens to multiple wallet addresses
- AWE Wallet integration
- ERC-20 token support
- Web3 transaction handling
- Multiple recipient processing
- Simple and responsive interface
- User-controlled transaction approval
- Non-custodial wallet interaction

## How It Works

1. Install the **AWE Wallet** Chrome extension.
2. Create or import a wallet in AWE Wallet.
3. Select or switch to **Base Network**.
4. Open Base Bulk Sender.
5. Connect AWE Wallet.
6. Select the token you want to send.
7. Enter the recipient wallet addresses and amounts.
8. Review the transfer details.
9. Submit the bulk transfer.
10. Review and approve the blockchain transaction using AWE Wallet.

## Non-Custodial

Base Bulk Sender does not require users to provide their private keys or recovery phrases.

Transactions are initiated by the application and must be reviewed and approved through **AWE Wallet**.

Never share your private key or recovery phrase with any website or application.

## Important

The **Connect Wallet** functionality requires AWE Wallet to be installed in the browser.

If AWE Wallet is not installed, install it from the Chrome Web Store first:

https://chromewebstore.google.com/detail/awe-wallet/pocegdpjahidghlpengkhaiancfpnapn

Then refresh or reopen Base Bulk Sender and connect your wallet.

## Security

Before approving a bulk transfer:

- Verify all recipient addresses.
- Verify the token contract.
- Verify each transfer amount.
- Make sure you are connected to Base Network.
- Review the transaction in AWE Wallet before confirming.

Blockchain transactions are irreversible once confirmed.

## Disclaimer

Base Bulk Sender is a Web3 utility for performing bulk blockchain transactions. Users are responsible for verifying wallet addresses, token contracts, transfer amounts, network selection, transaction fees, and transaction details before approving a transaction.
